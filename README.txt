PULSE&MOTION — ZUMBA & AEROBICS STUDIO WEBSITE
================================================

FILES
- home1.html, home2.html: two distinct homepage designs
- classes.html, gallery.html, about.html, contact.html
- login.html, register.html, forgot.html: standalone auth screens (no navbar/footer)
- assets/css/style.css: shared responsive styling and theme tokens
- assets/js/main.js: dark/light theme, RTL toggle, mobile navigation, demo form feedback
- assets/images/favicon.svg: custom favicon

HOW TO RUN
1. Extract the ZIP.
2. Open home1.html in a modern browser.
3. Navigate using the main menu.

CUSTOMIZE BEFORE PUBLISHING
- Replace the sample brand/contact details and sample address.
- Replace the Google Maps embed query with your actual studio address.
- The contact form and authentication forms are front-end demos. Connect them to a backend, form service, or authentication provider for real submissions and accounts.
- Photos load from Unsplash via internet; an internet connection is required to display them. Replace image URLs with locally licensed images if you want a fully offline website.
- Pricing, schedule, testimonials, address and contact details are illustrative placeholders.

FEATURES
- Responsive desktop/tablet/mobile layouts
- Consistent brand name, typography and color system across pages
- Light/dark theme toggle with saved preference
- RTL/LTR toggle with saved preference
- Social media icon links
- Accessible labels and image alt text
