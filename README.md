# Pulse&Motion — Zumba & Aerobics Studio Website

A modern, responsive, high-energy static website built for Pulse&Motion Zumba & Aerobics Studio.

- **Live URL**: [https://htmlstaticworks-org.github.io/Zumba_Aerobics_Studio/](https://htmlstaticworks-org.github.io/Zumba_Aerobics_Studio/)
- **Main Pages**:
  - `index.html` / `home1.html`: Primary energetic studio homepage
  - `home2.html`: Alternative studio homepage design
  - `classes.html`: Class schedules, format descriptions and booking
  - `products.html`: Studio gear, aerobic step platforms & workout accessories
  - `gallery.html`: Filterable high-energy aerobics photo gallery
  - `about.html`: Studio history, coaching staff and values
  - `contact.html`: Studio location, opening hours and contact form
  - `login.html`, `register.html`, `forgot.html`: Centered authentication screens with light/dark theme and RTL toggles
